## Remaining

**Pages (4)**
- **Sessions** (was Sentinel) — needs `SentinelViewModel` port, has dispatcher usage.
- **Game Boost** — needs `GameBoostViewModel` port, has dispatcher usage.
- **Guides** — needs `MarkdownView` control ported to Avalonia first.
- **Overview session cards** — the recent-sessions strip from the mockup is not built yet;
  the view-model already exposes `RecentSessions`.

**Platform services**
- Tray icon — Avalonia has a built-in `TrayIcon`; `TrayIconService` is WPF-specific.
- Click-through overlay + global hotkey — interop proven by the spike, not yet implemented.
- Single-instance mutex + show-window event.
- Elevation: `app.manifest` is currently `asInvoker` so the app can be launched repeatedly
  without a UAC prompt. Must return to `requireAdministrator` before release.
- Autostart scheduled task points at the WPF exe path — needs repointing.
- Notification and overlay settings are absent from the Settings page until those services
  exist. Adding the toggles before the services would be worse than omitting them.

**Cleanup**
- Turn compiled bindings back on (`AvaloniaUseCompiledBindingsByDefault`) once every view
  has an `x:DataType`.
- Delete `PrimeOSTuner.UI` and its four view-model test files once parity is reached.
- Validate self-contained single-file publish for the Avalonia app.
