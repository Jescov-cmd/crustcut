## Tooling worth knowing (saves hours)

- `Crustcut.exe --screenshot out.png [--screenshot-tab Id] [--screenshot-size WxH]`
  renders the app to PNG + writes `out.png.layout.txt` with every control's measured
  bounds. Win32 capture does NOT work (GPU-composited).
- `scratchpad/bughunt.py` cross-references DynamicResource usage vs defined keys,
  missing event handlers, suspect bindings. Run after ANY styling/theme change —
  dead keys fail silently and have bitten five separate times.
- Screenshot runs need a temporary `asInvoker` manifest flip (scripted pattern in
  history); ALWAYS restore `requireAdministrator` after.
- The running elevated instance locks its publish folder — publish each iteration to a
  fresh `publish/v0.8.0-bN` and rebuild the zip from it (python zipfile; Remove-Item is
  hook-blocked, PDB exclusion happens at zip time).
- Elevated kill/relaunch: `Start-Process powershell -Verb RunAs` one-liner (single UAC).
