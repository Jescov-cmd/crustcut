# v0.7 Design — Diagnosis tab, bloatware expansion, Xbox detection, button contrast

Approved by user 2026-06-10. Four parts, built in order; one publish at the end.

## Part 1 — Quick wins

### 1a. Lower button contrast (dark "Crust" theme)
The 3D pass made buttons read "too vibrant". Keep the glossy raised feel, reduce intensity:
- `GlassHighlight` top sheen: `#A6FFFFFF` → `#59FFFFFF`.
- `ButtonFaceBrush` lit-top stop: `#303034` → `#2A2A2E` (hover stop softened to match).
- `PrimaryButtonBrush` tan gradient: `#EAAE68→#8E5E2A` → muted bronze `#D29A5C→#7E5526`
  (hover dimmed equivalently). Boost ring / hero card / charts unchanged.

### 1b. Bloatware rows disappear when handled
After a successful Uninstall or Disable, remove the row from the on-screen list
(`BloatwareViewModel.Items`) instead of leaving it with a status label. Rescan
(`DetectAsync`) already only returns installed items, so this aligns immediate UI
with rescan behavior. No change to detection logic needed for this point.

## Part 2 — Bloatware expansion

### 2a. AppX catalog 25 → ~70 entries
Extend `bloatware-list.json` with: Win11 promoted third-party junk (TikTok, Instagram,
Facebook, LinkedIn, Spotify stub, Disney+, Prime Video, Netflix, Clipchamp, WhatsApp,
Messenger), Microsoft extras (Teams personal/MicrosoftTeams, Cortana legacy stub,
Power Automate Desktop, 3D Viewer, Paint 3D, OneNote store stub, To Do, Family,
Quick Assist, Office hub stub, Bing Sports/Finance, MSN apps), and OEM AppX
(HP/Dell/Lenovo/ASUS/Acer helper apps, McAfee store stubs). Rules:
- Same schema (appxName/displayName/category/tier/riskNote).
- Tiering follows existing precedent: anything load-bearing (Store, Photos,
  Calculator, Camera, Edge) stays `Risky`/`Blocked` with a risk note; pure junk is `Safe`.
- No entry without a one-line defensible reason it's bloat (project no-placebo rule).

### 2b. Desktop (Win32) program detection — NEW
- `InstalledProgramsClient` (PrimeOSTuner.Win): enumerates the three standard
  uninstall registry roots (HKLM\...\Uninstall, HKLM WOW6432Node, HKCU) returning
  (DisplayName, Publisher, UninstallString, QuietUninstallString, InstallLocation).
  Skips entries flagged SystemComponent=1 or missing DisplayName/UninstallString.
- `desktop-bloatware-list.json` (Core catalog): curated matchers — match on
  DisplayName prefix/contains + optional Publisher, e.g. McAfee, Norton/Norton 360,
  Avast, AVG, ExpressVPN OEM, WildTangent Games, Booking.com, HP Support Assistant /
  HP JumpStart family, Dell SupportAssist / Dell Optimizer, Lenovo Vantage adjuncts,
  ASUS GiftBox, Acer Collection. Each entry: id, match rule, displayName, category
  "desktop", tier, riskNote.
- `DesktopBloatwareDetector` (Core): pure matcher over the client's list; unit-tested
  with a fake client.
- UI: Bloatware tab gains a "Desktop programs" section beneath the Store-apps list.
  Action button is **Open Uninstaller** (launches the entry's UninstallString via
  Process.Start; never silent, never automatic — destructive actions stay opt-in).
  After launching, the row shows "Uninstaller opened — rescan after it finishes."
  Rescan removes entries that are gone.

## Part 3 — Xbox: detect custom install locations
`XboxLibraryScanner.EnumerateXboxRoots()` additionally parses the hidden
`<drive>:\.GamingRoot` file (binary: magic `RGBX` then UTF-16LE folder path,
null-terminated) that Windows writes when the user picks a custom Xbox install
folder. Union of: parsed GamingRoot paths + existing `<drive>:\XboxGames` convention,
de-duplicated. Parser is a small pure function with byte-array unit tests
(valid file, wrong magic, truncated, garbage). Failure → silently skip (same
defensive style as the rest of the scanner).

## Part 4 — "Diagnosis" tab

New nav tab "Diagnosis" between Sentinel and Settings. Two sections.

### 4a. On-demand scan ("Run Diagnosis")
`DiagnosisService` (Core) + thin scanners (Win) run checks, return
`IReadOnlyList<Finding>`: (Id, Severity Info|Warn|Problem, Title, Detail,
FixSuggestion, optional NavTarget). Checks (all "silent on uncertainty" — a check
that can't measure reports nothing rather than guessing):
1. **CPU throttling**: sample perf counter `Processor Information(_Total)\%
   Processor Performance` over ~3 s while issuing brief load; < 80% sustained ⇒
   CPU is power/thermal limited. Detail explains thermal vs power-limit causes
   (laptop on battery, dust, power plan).
2. **Background hogs**: top processes by CPU% (sampled twice, ~1.5 s apart) and
   working set; flag non-system processes > 15% CPU or > 1.5 GB RAM.
3. **RAM pressure**: > 85% used at idle ⇒ warn, with top RAM consumers.
4. **Disk space**: system drive < 15% free ⇒ warn (Windows + shader caches need
   headroom).
5. **Power plan**: active plan is Power Saver (or Balanced + no boost) ⇒ suggest
   Optimize tab's power tweak (NavTarget: Optimize).
6. **GPU driver age**: registry `DriverDate` of the active display adapter > 12
   months old ⇒ suggest update (no download automation).
UI: hero "Run Diagnosis" button → progress → findings list grouped Problems /
Warnings / Passed (passed checks listed so an all-clear is visible and honest).

### 4b. Live in-game detection (extends Sentinel)
New pure rules in `DetectionRules` (same Problem pipeline Sentinel already streams):
- **CpuThrottled**: rolling window — CPU busy (> 60%) AND % Processor Performance
  < 80% for 20 s ⇒ "CPU is being slowed by heat or power limits while you play."
- **BackgroundHog**: a non-game process sustains > 20% CPU for 20 s during a session.
- **DiskFull**: system drive < 10% free at session start.
`MetricsSnapshot` gains nullable fields for processor-performance % and top
background process (null ⇒ rules silent, preserving never-false-alarm).
Diagnosis tab shows live/recent in-game problems (same source the Sentinel tab
uses), each with plain-language fix text.

### Explicitly out of scope (YAGNI)
- No temperature sensors / kernel drivers (LibreHardwareMonitor rejected: AV flags).
- No nvidia-smi integration yet (possible later add-on).
- No auto-fixing from Diagnosis — it explains and links; fixes stay in their tabs.
